# “套个环”玩法逻辑

这一目录只整理 `subpackages/Interlocking/game.js` 的代码，没有复制图片、音频或场景资源。

## 代码位置

- `decoded/HomeController.js`：关卡构建、触摸输入、每帧推进、解锁、胜负和下一关。
- `decoded/Ring.js`：单个环的连接关系、旋转或平移限制、碰撞检测和退出动画。
- `decoded/Interlocking_GameData.js`：环类型、解锁位移阈值、关卡加载与本地进度。
- `decoded/Interlocking_Tool.js`：从 `Interlocking` 资源包读取 `Data/Min/lvN` 或 `Data/NoDeathRing/lvN` 等关卡配置。
- `decoded/InterlockingGameItem.js`：计时炸弹等关卡物件。
- `raw/`：同一批模块的原始混淆代码；`strings.json`：解开的字符串查找表；`manifest.json`：45 个模块索引。

`decoded/` 已替换 6,325 处字符串索引，适合阅读和比对；它仍保留构建后的短变量名与 Cocos 依赖，不是可直接导入的原始 TypeScript。

## 一局的核心流程

1. 加载关卡配置，创建环、碰撞体、连接关系和倒计时。普通关卡从 `Data/Min/lvN` 读取，另一模式从 `Data/NoDeathRing/lvN` 读取。
2. 触摸开始时从仍启用的环里选中命中触点的环。环按类型分为旋转和沿固定方向平移两类。
3. 拖动旋转环时计算目标角度，每帧最多推进 6 度；碰到其他环的多边形或触发点时拒绝该步旋转。拖动平移环时沿自身方向投影目标点，每帧最多推进 6 个坐标单位，并检查碰撞。
4. 检查解锁：平移环偏离初始位置超过该类型阈值乘缩放比例时移除；旋转环需要满足它与其他环的连接角度条件，也不能再被其他仍启用的环锁住。角度锁的容差是目标方向约 ±15 度。
5. 每次棋盘变化后重新检查解锁和胜利。所有环均被移除即过关；倒计时结束则进入失败流程。部分关卡还会按预设的剩余环 ID 检测死扣并提示。

## 可还原程度

上述交互、碰撞和胜负规则均在本地分包代码中。完整运行还依赖关卡 JSON、Prefab 和 Cocos 场景；这些资源没有复制到此目录。没有 source map，原始变量名和注释无法恢复。
