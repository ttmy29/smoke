## 全项目 UI 适配前置规则（以后修改界面先执行）

本规则适用于首页、打卡页、补盒页、互动页、结果页及以后新增的所有页面；不只针对某一个按钮。2026-09-29 的打卡页问题是反例：返回按钮与“每日烟票”标题直接使用 750×1600 设计稿上的 `y≈745`。工程用 `FIXED_WIDTH`，实际视口若为 414×780，换算后的 Cocos 可见高度约为 `750×780÷414≈1413`，顶部从 `y=800` 变为约 `y=706.5`；`y≈745` 已在可见区域外，于是导航被裁去。**设计分辨率不是运行时可见边界，也不能拿设计稿中心点替代页面布局规则。**

今后修改任何 UI 的位置、外框、字号或动画，必须先完成以下检查，再编码和验收：

1. **确认旧包最终规则和归属。**从 V1.0.8 对应页面配置、模板、最终级联 CSS 与组件规则确定原生导航/自绘导航、父容器、滚动范围、`rpx`/CSS `px`/百分比、最小高度、`max()`、断点、内边距和安全区；不能只抄第一处样式或按参考图取绝对坐标。打卡页原生标题是“每日烟票”，正文标题是“今天领一张烟票”，二者不是同一层。
2. **先计算实际视口，再确定锚点。**读取 Cocos `view.getVisibleSize()`、实际 CSS 宽高和设备像素比；顶部固定栏按 `visibleHeight/2 - 顶部安全区 - 栏高/2` 定位，底部固定栏按实际底边与安全区定位。正文按导航下方的可用区域布局，溢出交给 ScrollView；不能把 `1600/2`、`y=745` 或某个设备测得的 Y 值写成所有机型通用坐标。横向也要核对实际可见宽度和左右安全边。
3. **分清缩放的对象。**`FIXED_WIDTH` 只定义坐标换算，旧包 `rpx`、CSS `px` 与 `max(12px,24rpx)` 等仍须分别求有效值；父节点纵向缩放后，按钮框、文字、图标、描边和点击区不能无条件一起压扁。保持旧包规定的最小字号、最小点击高度与区域内边距，图文位置相对父框重新计算。
4. **逐项校准文字。**除了 `fontSize`，还要核对字重、行高、字距、基线、文字框宽高、左/中/右对齐、单行或换行、动态文案长度。Cocos `Label.Overflow.SHRINK` 可能静默缩小字，默认居中也会让本应左/右对齐的旧包文字整体偏位；必须明确选择溢出策略，并检查“今日烟票/今日已领取”、日期、序号、余额等所有状态。
5. **检查容器与层序。**导航栏固定在视口顶端，正文可滚动，弹层覆盖页面，背景色/渐变按旧包最终层序绘制；转场移动的是整页内容，不得让遮罩、背景、触摸拦截层或导航停在不同坐标系。返回和重新进入都要检查页面完全复位，不只检查转场中间帧。
6. **按多个视口验收。**至少核对 750×1600 设计视口、414×780、≤340px 窄屏、短屏及带顶部/底部安全区的设备；逐一记录导航、按钮、图标、文字外框是否完整可见，字号是否被缩小、文本是否换行/裁切，打开/返回动画的起点和终点是否正确。TypeScript 编译通过仅说明类型正确，不能代替运行画面验收。若未实测，状态必须写为“待视觉验收”。

这套顺序是**以后所有界面修改的前置要求**：先量运行时视口和旧包最终规则，再布父区域，最后排子控件与文字；修改一个尺寸时同步复核相邻元素、交互态与返回路径，不再只在 750×1600 下看单个节点。

王溪新盒初始必须为合盖状态。合盖时盒内 10 根烟完全不可见、不可点击；点击烟盒本体只触发约 500 ms 的开盖动画，动画完成后才露出并允许选择 10 个烟槽，不得在同一次点击中顺便抽烟。点击底部主按钮则遵循旧包分支：合盖时先播放同一开盖动画，动画完成后自动随机抽出一根；已经开盖时直接随机抽出一根。开盖或取烟期间锁定烟盒、烟槽和主按钮，重复点击不得重入。

开盒后的触摸边界也须与旧包层序一致：盒身正面覆盖在烟槽下半段之上，点击盒身只触发盒身点击逻辑（此时无动作），不能透过盒身选中被遮住的烟。2026-09-29 排查发现，Cocos 原先给整根 52% 盒高的烟槽节点绑定点击，尽管其下半段已被盒身遮住，仍可被命中并错误进入抽烟。现将烟槽点击区域裁至盒身顶部（盒高 30%）以上实际露出的烟段，盒身下方不再选烟；点击可见烟段和底部“来一根”的既有分支保持不变。

同一盒从会话或结果页返回首页后保持已开盖状态；产生一盒新烟时重新从合盖状态开始。直接点击某根烟只在盒盖已打开且该槽可用时生效。用户指出上一版开盖画面不正确；当前代码已按本节源码规则重新调整内外层显隐、移除独立的上部内侧竖条，并保留盒实例级状态和“来一根”续抽流程，但修正版尚未经用户浏览器视觉验收。

### 旧包开盖画面与层序

开盖动画必须按旧包固定几何交叉显隐实现，不能自行设计盒盖旋转、上抬、翻折或缩放动画：

1. 合盖时，盒盖外正面与外侧面不透明；盒盖内衬、内侧面、盒口、烟槽和白色内衬透明，烟槽不接收输入。

1. 王溪香烟的下部不能继续用目前的简单棕色长块和一条绿带交差。应按旧包 `life` 皮肤重建滤嘴：基色 `#b47f3f`、环带 `#173f37`、印记色 `#e0c097`，保留烟纸/滤嘴接缝、横向明暗渐变、细小纸纹与滤嘴标记，并绘制有体积感的底部椭圆封口。尺寸随会话几何统一变化，不能只对一张截图拼贴。
2. 未点燃时长按点火必须显示专门的打火机动作。首版默认沿用旧包 `ember-wheel`（普通打火机）分支：小机身按烟头几何定位在右下方，主要由火焰高度/宽度、火焰闪动、暖色光晕和烟头热度随 680 ms 进度变化；旧包没有“大机身从右侧横向滑进”的动画。提前松手取消，不留下已点燃烟头。火柴、电弧等旧包可选样式先不要求可切换。
3. 点燃后的正常待机画面，烟头上方应是**连续存在、持续向上延伸并自然弯曲的细烟轨**，不能整段淡出归零后突然重新出现。旧包实现为最多 4 条、每条最多 96 采样点，每约 75 ms 加点，点最多存活 6.8 秒，通常向上漂约 48 CSS px/s，并用渐变和多层透明笔画绘制。当前代码已删除循环取模的烟轨，改为持续采样、老化、材质坐标平滑噪声、根部偏移衰减及整轨多层笔画；Cocos 使用 750 设计宽度，速度按约 390 CSS px 预览宽度折算为 92 设计单位/s。
4. 烟头烟与人物吐气烟是不同层：这里要求的是从燃烧端升起的细烟，`READY` 和 `EXHALE` 继续生成；吸气时不新增烟头烟轨，但已有轨迹自然消散。不能用下方人物吐气粒子或中央吸气光圈替代。

验收：浏览器竖屏预览中，未点燃滤嘴、点火过程、点燃后静置至少 10 秒三个阶段连续观察；必须看到打火机动作、点燃状态变化，且静置期间烟头上方始终有相互接续的烟轨，没有周期性“全无烟 → 突然重生”闪断。对照旧包截图检查滤嘴、绿环、底部封口和烟轨起点/走势；截图未覆盖的细节以旧包绘制方法为依据。

当前代码：滤嘴仍用 `Graphics` 色条/细斑点、绿环、印记和椭圆底盖；680 ms 点火器与燃烧端已接入浏览器 Canvas 渐变/阴影，热度按约 140/280 ms 攻击/衰减并产生独立上升火星。烟体纵向位置、纸长/滤嘴高已按旧包 `sessionCigaretteRestGeometry` 的比例换算，并随当前可见高度更新；点火初始红热层按物理燃烧量从较薄状态增长，焦边改为 Canvas 渐变；灰帽使用 Canvas 渐变、裁剪与稳定材质坐标碎片。烟头烟轨在其后方按 75 ms 采点、6.8 秒老化，最多 4 条，已加入旧包材质坐标平滑噪声、根部偏移衰减和整轨多层绘制。人物吐气烟按强度一次发射，现用旧包参数的柔边纹理与 Cocos Sprite screen 混合近似；呼吸圈使用 Canvas 径向渐变。旧包可交互风场、灰离屏缓存/断裂、滤嘴材质及其他混合细节仍未等效；本次修改后的画面依用户要求由用户自行查看，不能将代码或编译通过写成视觉验收完成。

### 点火完成瞬间与满 3 秒吐气时的对照需求（2026-09-24）

点火开始阶段新增明确口径（2026-09-24，已编码待用户验收）：旧包 `startIgnition` 开始计时后，普通打火机的点火进度一旦大于 0，`drawCigarette` 就将烟纸端按已点燃形态绘制：焦黑折边、橙红燃烧层和随点火进度升温的煤点/亮点会与打火机火焰同时出现。**680 ms 是业务点火成功、进入 `READY` 的门槛，不是首次出现燃烧层的时间。**在进度恰好为 0 的第一帧仍可保持未点燃端；不能解释成按下瞬间已完成点火或已经进入 `READY`。热度目标随进度升至约 `0.82×进度`，完成后回落至待机目标 0.18；烟头细白烟只在 `READY/EXHALE` 新增，不要求点火按住期间提前冒出完整待机烟轨。提前松手/取消应恢复未点燃外观，不留下焦边或燃烧层。

当前 `CigaretteView` 已在 `LIGHTING` 正进度时开启焦边和燃烧层视觉预览，删除仅叠红色小条/亮点的替代画法；燃烧层渐变、煤点和亮点按旧包热度映射压低初期亮度。业务状态仍满 680 ms 才转 `IDLE`，取消时回到未点燃端并清除预览；烟头细烟仍只在点火成功后新增。对照同一视口录屏检查按下首帧、约 0.1/0.34/0.68 秒、提前松手和成功后静置；不能因代码分支已接入就判定形状、亮度或动态完全等效。用户自行在浏览器验收，本轮未由 Codex 打开浏览器。

- 比较点火后画面时，应固定同一视口、同一皮肤和**点火刚完成且尚未吸第一口**的时刻，另把“吸过后已经积灰的常态”单独比较；不能拿已积灰截图要求刚点燃瞬间出现灰帽。点火完成后，旧包 `tipDisplayGeometry`、`drawBurningTip/drawEmber/drawAshStack` 决定烟纸末端、焦黑层、红热层与无灰时的烟头位置，热度从点火目标回落到待机目标 0.18，打火机退场，随后烟头细烟从该几何锚点连续生长。本轮代码已将烟体纵向基准改为旧包比例，焦边、红热层、灰顶改用同一烟头几何，并让初始红热层按燃烧量起步；滤嘴仍由 `Graphics` 色条模拟，旧包材质缓存、精确噪声与阴影仍不同。不能因坐标已对齐就认定点火后画面等效。
- 满 3 秒从 `INHALING` 切入 `EXHALING` 时，人物嘴部吐气烟、中央白色呼吸圈、烟头上方细烟是三个独立效果。旧包吸气期间停止**新增**烟头轨迹，但已有轨迹保留并老化；吐气开始后在当时的灰帽顶（无灰时为燃烧端顶）新建轨迹。烟轨允许随风自然弯曲，不能要求完全笔直；根部应贴合烟头且弯曲由旧包材质坐标、锚点衰减、风场和分叉公式决定，不能因为阶段切换突然在烟头附近出现明显横向折弯或断裂。
- 旧实现给每点独立正弦横偏、每帧叠加横向速度，且逐段绘制渐变，是 3 秒切换时白烟根部可能弯得过急的代码原因。本轮已改为出生材质坐标、旧包 `tipSmokeTrailOffset` 平滑噪声与 `tipSmokeAnchorBlend` 根部抑偏，并按整条轨迹绘制渐变/三层笔画；旧轨迹保留、新轨迹从实时灰顶生成。旧包环境风场与所有平台混合细节尚未移植，连续动效由用户验收，本轮未由 Codex 打开浏览器。

### 吸气时灰帽与橙红燃烧层交界（用户新增，已编码待验收）

- 吸气期间灰帽应随真实消耗增长，橙红燃烧层按 140 ms 热度逼近变亮；灰帽始终紧贴其上方，不能在两层之间露出背景色细缝。松手后燃烧层回落到待机亮度，交界仍应连续；弹灰后残灰同样适用。
- 旧包 `computeCigaretteBurnGeometry → tipDisplayGeometry → drawEmber → drawAshStack/CigaretteTipMaterial.traceAsh` 共用几何。`traceAsh` 将灰帽底边延伸到火点顶部之内，重叠量 `min(0.75×(stickWidth/37.065), 0.25×ashHeight)`（旧包 CSS 绘制坐标），然后在火点之上绘灰，避免噪声边与抗锯齿共边产生背景缝。灰帽高 ≤0.45 CSS px 时不绘灰；灰尚未形成时不要求凭空显示灰帽。
- 当前 `SessionModel` 按消耗量增长灰，`CigaretteView.updateTipGeometry` 以燃尽段限制可见灰高。本轮已按旧包公式给灰帽底边加入重叠，灰帽仍在红热层之后绘制，`ashTopY` 与烟雾起点不变；灰帽可见阈值也按 CSS px → 设计单位换算。仅代码与静态检查完成，吸气时交界是否完全无缝由用户在浏览器查看；尚不能认定整体烟灰材质与旧包等效。

### 灰帽竖直轮廓（用户新增，已编码待验收）

- 旧包经典灰帽总体是**沿香烟轴线向上生长的竖直灰柱**，左右边接近烟身全宽且整体平行；只允许细小的不规则边缘与顶边噪声。没有弹灰动作时，不应整体倾斜、扭动或逐帧改变宽度；弹灰前约 80 ms 的短暂摇动属于单独动作。
- 旧包 `CigaretteTipMaterial.traceAsh` 以烟身中心和 `0.496×stickWidth` 半宽为左右基线，沿稳定材质坐标、约 `4×materialScale` 的纵向步长取噪声；顶部约 12 段细小起伏，底部按前节公式与燃烧层重叠。原 Cocos 代码主轴未旋转，但固定 `±39` 的宽度略窄，左右边和顶边使用周期正弦，不等效。
- 本轮已将左右基线、材料末端、材料比例、稳定哈希插值噪声与顶部 12 段轮廓按旧包方法移入；保留已做的底部重叠，灰帽顶部仍作为烟雾锚点。灰碎片纹理仍未使用旧包离屏缓存，弹灰前摇动与 140 ms 断裂尚未完成；轮廓只通过 TypeScript 和静态数值检查，浏览器画面由用户验收，不能宣称像素等效。

### 吸气燃烧端与弹灰粒子尺寸（2026-09-24，已编码待用户验收）

- 先区分材质与运动粒子：焦黑边由 `tipDisplayGeometry/drawBurningTip` 的共同轮廓和稳定噪声决定；26 个煤点、18 个热亮点固定在燃烧端材质坐标上，不能作为飞出的火星处理。吸气时热度目标为 1，松手后按约 280 ms 回落。当前已将煤点改为旧包固定哈希驱动的不规则多边形，亮点按烟宽比例设置椭圆半径，焦边振幅按烟宽/实际 CSS 比例计算，并按旧包先画燃烧层、后画焦黑折边。上次把暗色底层整块画在烟纸前，用户反馈变成黑团且遮住两侧橙色；本轮改为独立于烟纸**后方**的底层，并让烟纸上缘按旧包 14 段噪声路径绘制，保留燃烧层的两侧轮廓。烟纸纹理、阴影和 `burnContourOffset` 仍未完全等效，需用户查看。
- 独立上升火星须从当前燃烧端中心附近出生。旧包 `emitSpark` 初始半径 `1.2–3.4` CSS px、x/y 偏移分别约 ±4/±2.5 CSS px、寿命 `0.62–0.96 s`，向上扇形速度 `28–100` CSS px/s；`drawSpark` 按热度变色、半径随生命周期缩小到约 45%，并有 `6–10` CSS px 模糊光晕。当前用 `screen.windowSize.width / screen.devicePixelRatio` 得到实际 CSS 宽度，再计算设计单位倍率（与原 `view.getFrameSize().width` 换算相同但无弃用警告），按上述中心、尺寸、速度、重力、阻尼、热度和寿命生成火星。用户反馈此前纯 Canvas 火星不可见后，已将核心亮点改回 `Graphics`、Canvas 只负责模糊光晕；随机序列、逐帧调度和浏览器成像尚未证明等效。
- 经典弹灰的大块灰与细尘须分开还原。旧包灰块半径 `2.2–6.4` CSS px、横长椭圆（纵半径 `max(0.8,0.46×size)`），细尘 `size=1–3.8` CSS px、初始 `scale=.5` 后每秒增加 `1.8`，且有独立透明度阻尼；两者从**弹灰前燃烧端中心**发出，粒子数量按本次断灰比例算出的强度 `max(0.8,0.35+1.35×断灰比例)` 变化，附带 5 颗同规则火星。用户确认应以旧包原参数为准，已撤销此前大灰块半径的 `1.35×` 临时放大，恢复 `1×`；灰块仍为 Graphics 20 段旋转椭圆，细尘保持原尺寸。灰帽已补前 80 ms 摆动，但 140 ms 交互锁定/完整断裂、旧包随机流及 Canvas 栅格仍未等效。
- 验收以同一 CSS 视口和同一状态的连续录像为准：吸气初/中/满 3 秒分别核对焦边、煤点、上升火星的屏幕半径、出生点、数量/秒、亮度与寿命；积灰后连续两次弹灰核对灰块/细尘/5 火星的尺寸分布、形状、起点、散布、扩张及落底停留。参考图只定位元素，不能替代旧包方法参数。本轮未由 Codex 打开浏览器验收；已用 Creator 3.8.6 内置 TypeScript 编译器通过全项目 `--noEmit --skipLibCheck` 检查，编译通过不代表画面或声音已验收。

### 吸气音效播放规则（2026-09-24，已编码待用户试听）

- 当前吸气 MP3 与旧包 `audio/actions/inhale.mp3` 的 SHA-256 一致，声音素材本身不是差异来源。旧包 `SessionSoundController` 吸气音量为 `0.9`、不循环；开始吸气时从头播放，松手、触摸取消或满 3 秒结束时立即停止，之后只在进入吐气阶段时播放吐气音。不足 0.3 秒的短吸气应停止吸气音且不播放吐气音。
- 当前已将吸气/吐气改为可停止的主 `AudioSource`：退出 `INHALING` 时停止吸气，进入 `EXHALING` 才启动吐气，退出吐气或离开互动页时停止；吸气及临时轻吐气音量设为 `0.9`。首次按下时资源若尚未加载，只有该阶段仍有效才在加载完成后补播；弹灰用独立音轨，在吸气/吐气正播放时以 `0.28` 音量叠加，否则以 `0.58` 播放。总静音仍是单一开关，未实现旧包各项音效独立偏好。
- 旧包允许吐气未结束时开始下一口，并按吸气强度选轻/中/深吐气音；当前业务阶段仍仅允许待机吸气，吐气仍只有临时导入的轻音资源。这些是后续差异，不因本次修复吸气音停止时机而标记等效。用户自行试听松手、短按、满 3 秒、弹灰叠加及静音；本轮不由 Codex 打开浏览器。
