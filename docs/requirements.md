## 第一版需要做

1. 首页：展示可交互烟盒；能开盒、选一根烟并进入互动。演示版先固定一种皮肤，不做购买与解锁。
2. 抽烟会话：取烟、点火、待机、按住吸入、松开呼出、弹灰、抽完或手动熄灭。非法状态操作应忽略或给出反馈。
3. 香烟画面：滤嘴、烟纸、燃烧端、焦黑区域、烟灰随剩余量变化。
4. 特效：待机时烟头飘烟；呼出时有烟雾；弹灰时有灰屑下落和音效。复杂烟圈编队不在首版。
5. 结果页：按旧版烟盒来源的展示逻辑还原，不额外按结束原因改写单根标题；通常显示“这一根，抽完了”。内部仍区分自然燃尽与主动熄灭，展示本次数据并可回首页重新开始。旧版整盒用完/结算时的标题属于暂缓的库存功能，不在首版模拟。
6. 演示数据：本次会话先在内存流转；若保存到本机，存储代码须与画面分离。不承诺迁移旧小程序数据。
7. 音频：点火、吸入、呼出、弹灰临时音效，提供静音开关。

## 第一版验收

- Creator 预览中可完整走通“首页 → 取烟 → 点火 → 吸入/呼出 → 弹灰 → 结束 → 结果 → 首页”，无重复结束或状态错乱。
- 香烟缩短、烟灰增长/落下、烟雾与交互状态相符；离开互动页后不残留粒子和上一根会话状态。
- 不依赖微信登录、网络、广告即可演示；竖屏触摸可用。
- 借用素材的旧包来源及待替换标记可查。
- 首页和结果页的视觉结构参照 `visual-reference.md`；点火前互动页在该文档所列主要元素可见。
