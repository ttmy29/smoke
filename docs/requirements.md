## 第一版需要做

1. 首页：展示可交互王溪烟盒；可从当前盒的 10 个槽位中选一根进入互动，已取走的槽位持续为空。演示版先固定一种皮肤，不做购买与解锁。
2. 抽烟会话：取烟、点火、待机、按住吸入、松开呼出、弹灰、抽完或手动熄灭。非法状态操作应忽略或给出反馈。
3. 香烟画面：滤嘴、烟纸、燃烧端、焦黑区域、烟灰随剩余量变化。
4. 特效：待机烟头烟、点火、吸气热度/火星、呼出烟、灰帽增长与弹灰、基础圆形吐烟圈均按旧包方法实现和验收，不能仅以效果存在作为完成依据。复杂烟圈编队不在首版。
5. 结果页：按旧版烟盒来源的展示逻辑还原，不额外按结束原因改写单根标题；通常显示“这一根，抽完了”。内部仍区分自然燃尽与主动熄灭，展示本次数据并可回首页重新开始。旧版整盒用完/结算时的标题属于暂缓的库存功能，不在首版模拟。
6. 演示数据：本次会话状态仍在内存流转；浏览器本地分别保存“累计已抽香烟根数”和“当前王溪烟盒 10 槽状态”。自然抽完或主动熄灭的会话各计一根，取烟但未结束不计；结束回调重复到达不能重复加一。点选可用槽并成功开始取烟时，先记录该槽为空位，再播取烟动画；不能从累计根数倒推任意选中的空槽。首页“抽烟记录”显示累计根数，首页库存区显示“本盒剩余 N/10 支”与按剩余数点亮的十段短条；结果页显示真实槽位与剩余数。存储不可用或数据损坏时停用取烟并明确提示，不能默默补满。旧累计根数保留，新槽位存档首次从满盒开始；不承诺迁移旧小程序数据或跨浏览器/跨设备同步。
7. 音频：点火、吸入、呼出、弹灰临时音效，提供静音开关。

## 旧包方法级效果还原要求（用户新确认，覆盖此前“近似版”口径）

实现边界：`cc.Graphics` 继续承担可等效的轮廓、路径和细描边；连续渐变、柔边阴影、稳定灰纹理/裁剪、软烟纹理及混合效果须用材质、纹理、Mask、Sprite/粒子或 RenderTexture 完成。烟轨上升/风偏、火星发射、热度回落、灰帽增长/断裂属于独立的状态与时间规则，不能因更换渲染组件就视为完成。每项验收同时核对**规则、材质、运动、层序和清理**；旧包与当前实现的逐项差异、原因及方案见 [Canvas/Graphics 能力边界](legacy-rules.md#ccgraphics-能力边界与等效实现方案)。

本节是**必须达到的需求，不是当前完成状态**。图片只用于辨认烟头白烟、燃烧层、火星、灰帽、滤嘴和人物吐气烟在画面中的位置及前后关系；不得根据单帧图片猜动画、调出相似颜色后就视为完成。每个已纳入第一版的效果应从旧包对应方法核对：输入状态、触发时机、时间参数、生成数量、运动方程、锚点、绘制顺序、渐变/纹理/阴影、退出与清理。Cocos 不必照搬 Canvas API，但呈现和交互时序必须等效；`cc.Graphics` 无法表达的渐变、柔边或离屏纹理要使用材质、RenderTexture、Sprite/粒子等合适方案，不能以纯色圆、矩形、固定曲线冒充。范围外的烟雾实验室、特殊烟圈编队和非经典弹灰效果仍暂缓，不因本节自动纳入第一版。

### 吸气燃烧端与弹灰粒子尺寸（2026-09-24，已编码待用户验收）

- 先区分材质与运动粒子：焦黑边由 `tipDisplayGeometry/drawBurningTip` 的共同轮廓和稳定噪声决定；26 个煤点、18 个热亮点固定在燃烧端材质坐标上，不能作为飞出的火星处理。吸气时热度目标为 1，松手后按约 280 ms 回落。当前已将煤点改为旧包固定哈希驱动的不规则多边形，亮点按烟宽比例设置椭圆半径，焦边振幅按烟宽/实际 CSS 比例计算，并按旧包先画燃烧层、后画焦黑折边。上次把暗色底层整块画在烟纸前，用户反馈变成黑团且遮住两侧橙色；本轮改为独立于烟纸**后方**的底层，并让烟纸上缘按旧包 14 段噪声路径绘制，保留燃烧层的两侧轮廓。烟纸纹理、阴影和 `burnContourOffset` 仍未完全等效，需用户查看。
- 独立上升火星须从当前燃烧端中心附近出生。旧包 `emitSpark` 初始半径 `1.2–3.4` CSS px、x/y 偏移分别约 ±4/±2.5 CSS px、寿命 `0.62–0.96 s`，向上扇形速度 `28–100` CSS px/s；`drawSpark` 按热度变色、半径随生命周期缩小到约 45%，并有 `6–10` CSS px 模糊光晕。当前用 `screen.windowSize.width / screen.devicePixelRatio` 得到实际 CSS 宽度，再计算设计单位倍率（与原 `view.getFrameSize().width` 换算相同但无弃用警告），按上述中心、尺寸、速度、重力、阻尼、热度和寿命生成火星。用户反馈此前纯 Canvas 火星不可见后，已将核心亮点改回 `Graphics`、Canvas 只负责模糊光晕；随机序列、逐帧调度和浏览器成像尚未证明等效。
- 经典弹灰的大块灰与细尘须分开还原。旧包灰块半径 `2.2–6.4` CSS px、横长椭圆（纵半径 `max(0.8,0.46×size)`），细尘 `size=1–3.8` CSS px、初始 `scale=.5` 后每秒增加 `1.8`，且有独立透明度阻尼；两者从**弹灰前燃烧端中心**发出，粒子数量按本次断灰比例算出的强度 `max(0.8,0.35+1.35×断灰比例)` 变化，附带 5 颗同规则火星。用户确认应以旧包原参数为准，已撤销此前大灰块半径的 `1.35×` 临时放大，恢复 `1×`；灰块仍为 Graphics 20 段旋转椭圆，细尘保持原尺寸。灰帽已补前 80 ms 摆动，但 140 ms 交互锁定/完整断裂、旧包随机流及 Canvas 栅格仍未等效。
- 验收以同一 CSS 视口和同一状态的连续录像为准：吸气初/中/满 3 秒分别核对焦边、煤点、上升火星的屏幕半径、出生点、数量/秒、亮度与寿命；积灰后连续两次弹灰核对灰块/细尘/5 火星的尺寸分布、形状、起点、散布、扩张及落底停留。参考图只定位元素，不能替代旧包方法参数。本轮未由 Codex 打开浏览器验收；已用 Creator 3.8.6 内置 TypeScript 编译器通过全项目 `--noEmit --skipLibCheck` 检查，编译通过不代表画面或声音已验收。

验收必须覆盖连续录像/逐帧观察，而非单张关键帧：未点燃 → 680 ms 点火 → 静置至少 10 秒 → 按住吸气至 3 秒 → 松手/自动吐气 → 灰帽增长及弹落 → 再次静置。特别检查白烟确实持续**向上运动**而不是固定 S 线、火星独立向上飞、燃烧端按压变红亮且松手按时间常数回落、灰帽纹理不因增长跳变。按旧包动态规则与视觉层序逐项记录“已实现/差异/未验证”；未经旧包对照和动态验收，不得把简化替代品标为完成。

### 人物呼气白雾对齐（2026-09-24，已编码待用户验收）

- 本节特指从画面下方人物呼气位置发出的白雾，不是烟头细白烟，也不是中央白色呼吸圈。旧包默认 `natural-white`、`soft`、`standard`，`emitExhale` 满强度约 58 颗，当前同样一次发射约 58 颗，初始范围和寿命主体接近。
- 旧包烟团 96×96 离屏纹理的三团中心透明度约 `.64/.56/.46`，`drawSmoke` 按 `2i×1.56i` 拉伸、默认白烟用 `screen` 混合，透明度随更新按 `1-.42dt` 衰减。本轮已把三团纹理、椭圆比例、默认色 `#d9dad6`、`scale=.38` 初值及 `.62/s` 扩张、轻微旋转和透明度规则接入；去掉此前额外的 `(1-age/lifetime)^.7` 淡出，并用灰度强度纹理与 Sprite 的 `ONE / ONE_MINUS_SRC_COLOR` 混合因子实现默认白烟的 screen 算式。呼气粒子的 CSS px→设计单位改用实际帧宽，不再固定 `1.92`。
- 旧包 `SmokeWindField` 默认无阵风，只有手势吹散/转向时才产生风偏。当前首版没有这项已解锁手势，不应为白雾添加随机风；已移除原来的任意正弦横摆，保留旧包默认阻尼、浮升和旋转。仍未实现可交互风场、可选烟量/形状/颜色及旧包随机数序列；Cocos 的 screen 材质结果与 Canvas 像素成像尚待用户在浏览器验收，不可仅凭 TypeScript 编译通过标为完全等效。

### 吸气音效播放规则（2026-09-24，已编码待用户试听）

- 当前吸气 MP3 与旧包 `audio/actions/inhale.mp3` 的 SHA-256 一致，声音素材本身不是差异来源。旧包 `SessionSoundController` 吸气音量为 `0.9`、不循环；开始吸气时从头播放，松手、触摸取消或满 3 秒结束时立即停止，之后只在进入吐气阶段时播放吐气音。不足 0.3 秒的短吸气应停止吸气音且不播放吐气音。
- 当前已将吸气/吐气改为可停止的主 `AudioSource`：退出 `INHALING` 时停止吸气，进入 `EXHALING` 才启动吐气，退出吐气或离开互动页时停止；吸气及临时轻吐气音量设为 `0.9`。首次按下时资源若尚未加载，只有该阶段仍有效才在加载完成后补播；弹灰用独立音轨，在吸气/吐气正播放时以 `0.28` 音量叠加，否则以 `0.58` 播放。总静音仍是单一开关，未实现旧包各项音效独立偏好。
- 旧包允许吐气未结束时开始下一口，并按吸气强度选轻/中/深吐气音；当前业务阶段仍仅允许待机吸气，吐气仍只有临时导入的轻音资源。这些是后续差异，不因本次修复吸气音停止时机而标记等效。用户自行试听松手、短按、满 3 秒、弹灰叠加及静音；本轮不由 Codex 打开浏览器。
