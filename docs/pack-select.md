首页滑盒已独立接通，详情见 [首页滑盒](home-pack-browser.md)。首页集合按旧包取得条件过滤，默认八款，不能将本页十款目录直接用作首页列表。两处共用皮肤、PackBoxView 裁切／品牌绘制及只读任务进度；首页使用 home 模式，目录沿用 catalog 模式。本轮未将浏览转换为永久解锁或真实多盒库存。

散烟盒入口更新（2026-10-16）：整行点击（含“进入”）已打开独立 LooseBoxPanel。返回通过 suspend／resume 保留本页滚动和卡片；内部“我的收烟榜”可进入并返回散烟盒。容量摘要和页面当前均无社交库存源，显示未知。旧包依据、页面／详情和业务接口见 [散烟盒](loose-box.md)。下文静默接口仅适用于尚未接入的业务，不能替代已完成导航。

## 当前范围（2026-10-16）

按用户最新要求，选盒页以旧包 V1.0.8 的目录代码为 UI 基准。未完成业务只保留回调，页面、按钮及点击后均不显示“未开放／未接入”等额外说明。不播放广告、不保存解锁、不扣烟票、不增加库存。已编码，效果由用户验收。

## 入口与布局

`side/record3/bg`（兼容 `record-002`）经 HomeController → DemoFlow 打开独立 PackSelectPanel。开盖、取烟期间阻止进入，返回恢复首页；进出为 0.3 秒滑动。首页持续可见于选盒页下，选盒面板固定根节点的 BlockInputEvents 拦截输入，只有内部 page 平移，避免过渡露出相机黑底。原补盒页入口未纳入本轮。

打开散烟盒时用 `suspend(true)` 保留选盒页绘制，暂停按钮、ScrollView 和布局更新，停止惯性滚动；返回 `resume()` 恢复交互与原内容。默认 `suspend()` 仍可停用隐藏页面。该修正已通过状态与类型检查，未进行视觉验收。

正文参照旧包 catalog：深色背景、标题和烟票图标读数、原派烟说明、散烟盒托盘／容量／“进入”及箭头、两列十款烟盒、锁态条件和“看广告直接解锁”、首盒免费／当前／典藏标记，以及原页底说明。没有开发状态标签、缺图或加载文字，资源错误仅记控制台。

尺寸统一在 750 单位下绘制，再整体乘画布宽／750；实际 CSS 宽仅选择 ≤340px 分支。常规外边距 28、行列距 24／20、烟盒视觉区 252×374；窄屏外边距 20、间距 18／14、视觉区 224×334。卡片按旧包图片区、拟味、状态栏的空间组合，不使用任意首页缩小倍率。

## 烟盒绘制

PackBoxView 根据旧包 pack-box.wxss 及目录覆盖规则绘制闭盒：普通盒宽为视觉区 86%，高为 100%；正面 left 13%／width 84%，侧面 left 5%／width 8%，盒盖 top 6%～30%，盒身 top 30%～96%。文字使用目录专用字号：名称 34、代码／页脚 13，盒盖代码 20，特定长代码 17。

盒盖、正面、侧面和盒盖侧面分别裁切同一皮肤，普通正面宽 122%／高 136.364%、盒盖宽 122%／高 375%、侧面宽 560%。加入底影、侧面渐变、独立品牌文字与页脚。createPackSkin 和文字阴影函数与主页共用；主页开盖、库存及入场逻辑保持原行为。

无影烟按旧包 opacity:0 不绘制盒体，卡片和锁态仍保留。祖国使用旧包指定远程皮肤（本轮已取得并导入），采用其专用 24% 分界、125%／500% 裁切及测量公式 h=min(视觉高,视觉宽/.7)、w=.602h、半厚度=.1w，23° Y 轴方向及独立侧面；身份由原图呈现。未对 Cocos 与 CSS 的投影、阴影或栅格结果做视觉等效验证。

## 数据和预留接口

### 解锁进度接入（2026-10-16）

`DemoFlow` 已提供 `createPackUnlockProgressReader` 作为 `readPackState`。煊赤门使用 AchievementStore 中 `completed=true` 的条目数（含特殊成就，与未读无关），显示如 `14 / 30`；红搭山使用 ProgressStore 的累计结束根数，目标 50；黄鹊楼／英蓉王／欢囍使用 CheckInStore 最长已知连续天数，目标分别为 2／7／14。每次进入读取最新值，分子限制在 0～目标范围。当前累计根数沿用项目既有存档口径，也包括此前显式初始化的累计值，不从记录页伪造历史。

分享次数保留 `readShareCount` 接口，未提供时为“— / 10”；数据损坏或读取失败同样显示未知，不将其填成 0。华孑为兑换条件、无影烟和祖国为特殊款，按旧包不加普通任务分数行。进度位于解锁条件下方、“看广告直接解锁”上方。

本轮仍不执行永久解锁。即使显示 `30 / 30`，也不写烟盒状态、创建库存或扣票；后续业务接入方可替换 readPackState 提供真实永久解锁结果。

CheckInStore 新增可选 `maxStreak` 字段，打卡时保留峰值，断签及重新启动不清除；旧存档读取现存 streak 和打卡流水中的最长连续段作为已知证据，后续打卡保存该峰值。更早且已丢失的历史峰值无法凭空恢复，旧档显示最长已知值；本轮不重置或补造历史。readSnapshot 的当前连续天数行为保持原样。

回归命令：`node tools/test-pack-progress.cjs`，覆盖已读成就仍计数、14/30、封顶、未知与真实 0 的区别、只读不解锁、断签／重启与旧档恢复。仅业务检查，画面由用户验收。

PackSelectActions 的必需接口为 onBack、readPack、readTickets。王溪与余额读取真实本机数据；其他数据未知时为“—”，不伪造已解锁、库存或进度。当前存档没有 sealState，不能将盒盖关闭说成未开封，因此王溪显示真实剩余数；未来数据源可单独提供 sealState。

| 可选接口 | 用途 |
| --- | --- |
| readLooseBox | 返回 available／capacity；缺失显示“— / — 根”，托盘保留旧包结构 |
| readPackState(id) | 永久解锁、选中、剩余、封装状态、序号及真实进度；未知时不构造进度 |
| onEnterLooseBox() | 散烟盒整行点击，包含“进入”区域 |
| onSelectPack(id) | 已解锁卡片选择；未传时点击当前王溪返回首页 |
| onLockedPack(id) | 锁态卡片点击 |
| onUnlockAd(id) | “看广告直接解锁”按钮；本轮只调用接口，不改变状态 |
| onGift(id) | 独立派烟按钮 |
| onNationalDetail() | 已解锁祖国卡片的详情按钮 |

setActions 可替换接口。散烟盒导航已由 DemoFlow 提供，其他没有提供的可选业务回调点击静默；广告、派烟、详情阻断父卡片事件，不误触选择。回调自身的实际业务和完成后刷新由后续接入方负责。
