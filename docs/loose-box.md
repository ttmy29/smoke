## 数据及业务接口

`LooseBoxModel` 定义 `LooseBoxSource.readSnapshot()`，返回真实等级与烟支列表；`LooseCigaretteItem` 支持来源、时间、单根／五根、头像、徽章、烟盒、外观及特效说明。读源失败、等级无效、重复 ID 或超容量时视为未知，不覆盖存档。

当前项目没有好友接烟库存，`DemoFlow` 使用 `emptyLooseBoxSource`。容量／支数和升级目标显示“—”，正文保留旧包空盒构图，不制造“0 / 1”库存或示例好友；初始管状盒仅为默认容器绘制，不代表已取得该等级。后续接入时应给选盒摘要和散烟盒页面提供同一个真实数据源。

| 接口 | 行为 |
| --- | --- |
| `LooseBoxController.setSource(source)` | 替换数据源，页面可见时刷新，数量按每项 quantity 求和 |
| `onBack / onHome / onRanking` | 必需导航，现已接通，不用空回调代替页面 |
| `onUpgradeAd(nextLevel)` | 广告升级接口，未知等级时参数为 null |
| `onSmoke(id?)` | 指定烟支／整组；不传 ID 表示随机取烟 |
| `onDiscard(id)` | 仅在确认丢弃后调用 |

业务回调返回 boolean 或 Promise<boolean>。仅明确返回 true 且页面仍有效时读取源刷新；不提供回调或返回 false 时不伪造成功、移除烟支或增加容量。回调负责真实广告校验及库存事务。抽取与丢弃成功后关闭详情；页面离开后晚到结果不重建页面，进行中的操作防重复提交。

头像请求去重、缓存，晚到结果仅更新有效节点；持有的 ImageAsset 引用和运行时纹理在销毁时释放。正文重建和详情关闭会释放对应 CanvasTexture。当前仍沿用工程浏览器 CanvasTexture 桥接，未完成微信／原生平台适配。
