### 941 画布尺寸对比修正

通用的单位区分、统一倍率、避免重复缩放及后续开发检查项见 [UI 易错点与复用约定](ui-pitfalls.md)。新增同类 UI 前先检查该约定，避免再次只调整图形而遗漏文字和卡片尺寸。

原问题是色点、选择框和边距按设计宽度缩放，但名字／说明、卡片最小高和列间距按实际 CSS 宽度反算。在 CSS 预览宽度也是 941px 时，名称仍为 14px，色点却约 43px，比例失衡。现在统一采用 `941 / 375` 的手机构图倍率，实际浏览器宽度仅决定是否进入窄屏单列。

| 项目 | 旧包 375px 手机基准 | 当前 941 设计宽换算值 |
| --- | --- | --- |
| 圆色点直径（不含外圈） | 34rpx ≈17px | ≈42.7 |
| 名称字号 | 14px | ≈35.1 |
| 说明字号 | 12px | ≈30.1 |
| 卡片最小高度 | 64px | ≈160.6，随文字撑高 |
| 两列间距 | 8px | ≈20.1 |
| 选择框直径 | 28rpx ≈14px | ≈35.1 |

普通两列卡片各为 341 布局单位（当前约 427.8 设计单位）；窄屏按旧包 24rpx 侧距改单列。名称行高按 1.35、说明按 1.45，颜色区标题按 18px 手机字号、说明按 12px；当前 UI 预览说明缩短以减少额外换行。以上均为源码单位对比，未做截图量取或画面验收。

## 真实模式的数据和交互（关闭 UI 预览时）

`SmokeLabModel` 保存选项目录与方案类型；`SmokeLabStore` 处理持久化、优先级和权限；`SmokeLabController` 负责页面。入口与会话往返交给 `DemoFlow`。无需挂脚本或制作新预制体。

| 内容 | 实现 |
| --- | --- |
| 保存范围 | 本盒、本烟种、全局；本烟种和全局保存先确认。当前烟盒实例 ID 和种类由 PackStore 提供，只有王溪可实际使用。 |
| 优先级 | 本盒 → 本烟种 → 全局 → 默认。本烟种保存清除该种类的单盒覆盖；全局保存清除全部下级覆盖。将来新增同种烟盒会继承烟种／全局方案。 |
| 恢复默认 | 选择本盒／本烟种／全部并确认。本盒或本烟种写入明确的“系统默认”标记，阻止继承上级自定义；只恢复外观，不清除互动开关。 |
| 草稿 | 色彩、形状、吐雾方式和烟量先改草稿；保存成功后更新来源并清除未保存状态。返回有修改时确认继续编辑／放弃修改，取消确认保留草稿。 |
| 每日权限 | 三种颜色各自的整套调色板、吐雾方式与烟量、非圆形烟圈、无限圈、四种编队分别授权。跨日失效，已保存外观仍保留并渲染；过期只禁止继续编辑，不强行恢复默认。 |
| 分组续期 | 符合资格的形状／编队全部发现后，可次日一次续期整组；任务尚未开放的选项不伪造发现记录。 |
| 错误与过期 | 不覆盖损坏存档；写入失败不提示成功。保存校验当前烟盒，过期上下文和跨日返回的解锁结果不发放权限。 |
| 本机存档 | 新键 `smoke.lab.v1`，已加入启动重置和设置页容量统计。保留至多 128 个单盒覆盖，当前只有一个可选烟盒；坏数据返回不可用。 |

## 已保留的抽烟页联动代码

本节为此前实现并保留的真实模式消费代码，本轮没有继续调整粒子或轨迹；当前 UI 预览不写它读取的真实方案和权限，后续具体效果通过上方回调接入。

- 抽烟页“实验室”已开放同一页面。进入时结束当前按住动作并暂停会话更新，返回同一根烟，保留消耗、口数、时间和烟圈计数；不重新抽取或扣库存。
- 开始抽烟、从实验室返回和会话每秒刷新方案／权限；余烟色传给 `CigaretteView`，呼出色／烟圈色、烟量及轨迹传给 `BreathEffects`。
- 普通烟圈仍需吐气且每根 3 次；今日无限权限只放开次数，不绕过吐气阶段。到期重新按本根原有计数判断，不能通过开关重置次数。
- 吐气时从烟圈按钮向左／右／上滑动，按距离／时长计算初速度；手指拨烟开启后可在中间交互区滑动推动人物烟雾及烟圈；编队开启后出现“触发编队”，吐气时可触发。
- 新样式使用当前 Cocos 粒子／Canvas 桥接实现。普通三种可解锁形状（爱心、方形、花瓣）、六种轨迹和四种编队已有渲染分支；颜色、烟量与互动已有消费配置的实际代码。完整旧包风场、各样式逐参数动画、文字烟圈的祝愿成字与节日双色动画、手机安全区及字体像素尚未等效，不把代码分支存在写成旧包动态验收通过。
