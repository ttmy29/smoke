# 旧微信包 vs 当前 Cocos 工程：规则差异

> **V1.0.8 基准补充（2026-09-29）：**本表原审计基于 V1.0.7，尚未逐项重跑 V1.0.8 全包审计。当前旧包验收基准已改为 V1.0.8，文件选择规则见 [旧包参考](legacy-reference.md)；表内结论与 V1.0.8 冲突时，以 V1.0.8 为准。

审计日期：2026-09-24。旧包证据与逐方法规则见 [旧包规则审计](legacy-rules.md)，全包静态入口见 [模块／方法索引](legacy-module-index.md)。当前实现以 `assets/scripts/` 为准。本表的“接近”只表示行为方向相同，**不是帧级或像素级相同**；“缺失”不等于旧包没有。

## 领域规则

| 项目 | 旧包 | 当前 Cocos | 判定／影响 |
| --- | --- | --- | --- |
| 初始状态 | `STICK_EXTRACTING`，取烟确认后 `IGNITION`，且锁定烟盒槽位 | 新会话直接 `UNLIT`；转场单独由 `DemoFlow` 做，无库存槽位 | 流程近似，数据规则不同 |
| 点火 | 长按 680 ms；提前松手取消；确认后 `READY` | `lightingSeconds=0.68`，提前松手取消，转 `IDLE`；已有点火进度和普通打火机火焰 | 核心时长一致；旧包重试文案、四种器具选择及完整火焰动态仍未实现 |
| 点火中的烟头外观 | 点火进度 `>0` 即绘焦黑折边和燃烧层，火点热度随进度上升；业务仍是 `IGNITION`，680 ms 后才进 `READY` | `LIGHTING` 正进度已改为焦边/燃烧层预览，初期颜色与阴影按旧包热度映射；满 680 ms 才进 `IDLE`，烟头细烟此后新增 | 时间分支已编码对齐；烟头轮廓、煤点位置、亮度和取消时动态尚待用户同视口验收，不宣称视觉等效 |
| 吸气长度 | 1–3000 ms，整毫秒四舍五入；3000 ms 自动结束 | 连续秒数，最短 0.001 秒，满 3 秒自动结束 | 边界近似；毫秒量化不同 |
| 松手/取消 | 正常松手提交；触摸取消按 0 ms，**不消耗** | `TOUCH_CANCEL` 与普通松手共用 `handleRelease` | **不一致**：意外取消也可能耗烟/计一口 |
| 吸气次数 | 每次 ≥1 ms 的提交追加 puff，记录起点、时长、消耗、视觉快照 | 仅累加 `inhaleCount` 和 `lastInhaleSeconds` | 统计数量相近，明细与快照缺失 |
| 燃烧量 | 千分点整数，`round(100×累计吸气毫秒/3000) - 已消耗`，本次至少 1‰，满 3 秒约 100‰ | `remaining -= deltaSeconds/30` 逐帧浮点累计 | 满口近似；短口、跨帧舍入、累计守恒不同 |
| 待机燃烧 | 无时间驱动扣烟 | `idleBurnPerSecond=0` | 一致 |
| 吐气门槛 | 本口严格 >300 ms | 严格 >0.3 s | 语义一致，边界受毫秒量化差异影响 |
| 吐气持续 | 与本口吸气时长相等 | `lastInhaleSeconds` | 基本一致 |
| 吐气中再吸 | 旧 `startCyberInhaleV3` 允许 `EXHALE`；组件有交接和约 180 ms 待启动 | 仅 `IDLE` 可吸；吐气中按住被忽略 | **缺失** |
| 自然燃尽 | 吸气结算后若需吐气，先吐完再 `FINISHED` | `consume` 一旦归零立刻 `FINISHED` | **不一致**：最后一口烟雾可能被跳过 |
| 手动熄灭准入 | 烟槽确认后，`IGNITION/READY/INHALE/EXHALE` 可熄，写结束时间和结果 | 入场预览期间按钮阻止操作；进入互动页后 `UNLIT/LIGHTING` 对应旧包 `IGNITION` 的点火前/点火中，均可熄灭，已结束后拒绝 | 点火前可熄符合旧包；仍需核对取烟交接与重复点击时的结算边界 |
| 熄灭后的香烟画面与跳页 | `stopSession` 结算后经 `completeAndRoute` 停止逐帧绘制并立即提交、跳结果；正常路径没有固定时长的熄灭后香烟展示动画 | 熄灭按钮成功后同步停止音频并调用一次结果页切换，不再渲染 `EXTINGUISHED` 香烟或等待 0.65 秒；本机存档失败只在结果页提示 | 正常收尾时序已编码待浏览器验收；异常存档仍缺旧包式重试 |
| 会话存储与累计根数 | schema v3 进行中会话、烟盒/钱包/任务热状态、设置、事务日志和历史页分开存；报表累计根数取已结束会话记录数（含自然抽完、主动熄灭） | 进行中会话仍仅在内存；新增版本化浏览器本地计数，结束后按本根 ID 去重加一，首页与结果页读取显示 | 只对齐累计根数口径；旧包的完整记录、断点恢复、库存/钱包/任务、历史分页与事务恢复仍未实现 |
| 结果标题 | 烟盒来源单根通常“这一根，抽完了”，结果数据来自实际记录 | 同一标题；口数/时长/弹灰数来自本次内存 | 文案一致，持久化与库存不同 |

## 灰、烟、音效与输入

| 项目 | 旧包 | 当前 Cocos | 判定／影响 |
| --- | --- | --- | --- |
| 灰长度 | `ashLength += burn‰/1000×1.86666…`，另计超量 `ashDrop` | `ash += 消耗比例×1.8667`，上限 1，无 `ashDrop` | 增长近似，过量行为不同 |
| 灰阈值 | 首次 0.56–0.70、以后 0.36–0.50，稳定随机；只控制临界视觉/预警 | 已移除 `0.56` 点击硬门槛；当前未生成与使用旧包灰预警阈值 | 点击准入已对齐，临界视觉仍缺 |
| 允许弹灰 | `ashLength>0 || ashFlickCount>0`，且状态为待机/吸/吐 | 已按同一状态与灰/历史条件判定，拒绝时显示原因 | 业务条件已编码对齐，浏览器效果待用户查看 |
| 弹后残灰 | 原灰的 10%–82%，由会话 ID 与次数生成的确定性随机数决定；重算下一阈值 | 已按 `0.1+0.72×稳定随机数` 保留残灰并可重复弹；当前随机种子未接会话 ID，也未重算预警阈值 | 残灰范围一致，种子/阈值仍不同 |
| 弹灰手势 | 按钮及加速度晃动；晃动阈值 0.9、窗口 120 ms、冷却 1 秒 | 只有按钮 | 缺失晃动 |
| 弹灰画面 | 灰帽 140 ms 折断、前 80 ms 抖动；约 8–10 大块灰、`round((18–36)×断灰强度)` 颗细尘且至少 8 颗、5 火星，部分沉降停留 | 已分出灰块/细尘/5 火星并允许灰块落底；灰帽前 80 ms 摆动已补，仍无 140 ms 完整断裂/交互锁定 | 可见落灰已编码，断裂层序不等效 |
| 吸气火星大小与运动 | `emitSpark` 半径 `1.2–3.4` CSS px，从燃烧端中心 x±4/y±2.5 CSS px 发射；寿命 `0.62–0.96 s`，按向上扇形速度、热度衰减和模糊光晕绘制 | 已按实际 CSS 宽度换算半径与速度，改从燃烧端中心扇形发射；用户反馈纯 Canvas 火星不可见后，核心改用 Graphics 绘制，Canvas 仅画光晕 | 主要公式已编码；这次显示链路修复仍待用户观察上升过程，随机流和尺寸也未证明等效 |
| 燃烧端煤点、亮点与焦边 | 26 个固定材质煤点为宽约 `0.055–0.175×stickWidth` 的多边形；18 亮点按 `stickWidth/37.065` 缩放；焦边用 `charTop/BottomAmplitude` 与稳定噪声，暗色底层位于不规则烟纸上缘**后方** | 26 煤点、18 亮点按烟宽缩放；用户反馈黑团后，暗底已移到烟纸后方，烟纸上缘改 14 段旧包轮廓，不再整块覆盖两侧橙色 | 修复层序原因；新画面待用户验收，纹理与阴影仍未等效 |
| 弹灰灰块与细尘大小 | 灰块半径 `2.2–6.4` CSS px，椭圆纵半径 `max(0.8,0.46×size)`；细尘半径参数 `1–3.8` CSS px、初始 `scale=.5` 且每秒增加 `1.8`；从弹灰前 `emberCenterY` 发射，数量随断灰强度变化 | 已撤销 `1.35×` 临时放大，大灰块恢复旧包 `1×` 半径；细尘保持原尺寸，灰块仍为 Graphics 20 段旋转椭圆 | 半径公式已恢复；屏幕尺寸仍需同视口验收，随机流与 Canvas 栅格仍不同 |
| 烟头细烟 | 最多 4 条×96 点，75 ms 采样、6.8 秒保留；每点出生材质坐标、分叉、风、纵向渐变、多层笔画 | 已加入出生材质坐标、根部衰减、平滑噪声、分叉与整轨渐变/三层笔画；未移植环境风场 | 主体公式更接近，动态未验收，仍非方法级全等 |
| 中央吸气圈 | 中心 `(w/2,0.47h)`，半径到 `min(.36w,.19h)`；径向渐变＋双细描边 | 已按实际可见高度计算中心与半径，使用 Canvas 径向渐变与双描边 | 几何随视口适配；画面待用户验收 |
| 吐气白圈 | 本口强度乘吐气剩余进度；径向渐变 | 已按本口强度/剩余进度缩小并用 Canvas 径向渐变 | 未做旧包逐帧对照 |
| 人物吐气起点 | 横中、`0.68h–0.78h`；一次性按强度、烟量与风格发射粒子 | 横中，按实际可见高度及底部内缩计算；进入 `EXHALING` 时一次发射 | 发射时序和随视口调整已接近；具体口部锚点、风场及画面仍待用户验收 |
| 人物呼气白雾 | 默认自然白、soft/standard；满强度约 58 颗，上限 220；烟团初始 `scale=.38` 且每秒增 `.62`，96×96 纹理三团中心透明度 `.64/.56/.46`，绘制为 `2i×1.56i`，默认白烟用 `screen` 混合；透明度按 `.42/s` 衰减，风偏需交互手势触发 | 已恢复三团纹理、椭圆比例、色值、逐颗扩张/旋转、透明度规则及实际视口 CSS 缩放；用灰度强度纹理和 Sprite `ONE / ONE_MINUS_SRC_COLOR` 模拟 screen，默认无手势时不再加任意正弦风 | 默认规则已编码待用户动态验收；Cocos 与旧包 Canvas 成像、随机流及可交互风场仍未等效 |
| 基础吐烟圈 | `EXHALE` 可触发，每根默认 3 次；吸气中/其他状态分别提示；`emitRing/update/drawRing` 用 40 个柔边烟团描圆，扩大上升、约 4.4–5.8 秒寿命 | 按钮已启用；模型限制阶段和 3 次计数，非吐气显示对应提示；Canvas 绘制默认圆形烟圈并按旧包主要参数推进 | 已编码且模型测试通过；浏览器画面由用户验收，特殊形状/编队仍暂缓 |
| 音效 | 点火 4 种；吐气按强度选轻/中/深；弹灰可叠加吸/吐；单项偏好、环境声交叉淡入淡出 | 临时点火/吸气/轻吐气/弹灰各 1 音；吸气现用同一旧包 MP3、音量 0.9，不循环，退出吸气即停止；弹灰独立叠加，加载期间可取消待播；仍只有单一静音开关 | 吸气启停与弹灰叠加规则已编码待用户试听；吐气强度分档、点火选型、独立偏好与环境声仍不等效 |
| 麦克风/环境/实验室/派烟 | 旧包有对应业务、权限或效果控制 | 仅不可用占位 | 首版范围差异 |

## 取烟、几何与帧调度

V1.0.8 新增固定底部自定义导航：“来一根／全服”两等分，内容区预留 `57px + safe-area-inset-bottom`；导航背景 `#0d1010`、顶边 `#514739`，图标 20 px、文字 11 px，选中项使用暖金色并在顶部显示 24 × 2 px 橙色指示条。当前 Cocos 已增加香烟／地球图标、两项文字、首页选中态和固定底部占位，按 CSS 像素与当前视口宽度换算设计尺寸；两个按钮点击静默无效果。浏览器动态画面及非零手机安全区尚未验收；它与上方橙色“来一根／补一盒”主按钮不是同一控件。

**仍不一致。** 已有浏览器 Canvas 纹理桥接渐变/柔边、热度与火星、稳定灰碎片、基础烟圈及弹灰业务修正；旧包的精确噪声/风场、灰纹理离屏缓存、灰帽断裂、屏幕混合与全部时序仍未完成方法级动态验收。布局目标接近参考画面，不能宣称材质、轨迹、时序或像素一致。本轮依用户要求不由 Codex 打开浏览器确认修改后的画面。
