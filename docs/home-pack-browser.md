## 当前实现

`HomePackBrowserModel` 管理只读首页集合、主按钮文案和手势判定，`HomePackBrowser` 负责独立视口、轮播状态、锁态和皮肤生命周期，避免继续把所有逻辑堆进 HomeController。

真实王溪 PackRoot 移入视口的 LifePage，仍使用原节点、开盖状态、烟支槽位和取烟计算；不会为了轮播重建或复制一盒王溪。其他款复用 PackCatalog、PackBoxView 的盒体／裁切／品牌文字及已导入皮肤，新增 home 绘制模式，目录默认模式保持原有规则。首页模式使用首页字体与相对定位，锁态盒体宽除以 1.06、高度乘 .78，皮肤灰度／变暗，独立锁、条件及数值进度。不会直接放大目录卡片或重复导入图片。

首页轮播只变换当前与离开页，结束后保留当前页；总数和索引从实际集合产生。普通切换为 280ms，当前未接系统减弱动态偏好。视口 Mask 将绘制限制在烟盒区域，避免切换时跨到右栏。

王溪保留原 502×728 和中心 (-185,-50)，不再由旧工作区纵向缩放反算。导航从被弃用的整页 Flex 页脚中分离，使用 375px 参考宽统一换算：按左列宽对齐，放在实际盒体底边下方，并读取底部预制体格言的实际边界，防止提示文字覆盖格言。保持预制体原有位置；44px 点击区与可见文字分别计算。实际 CSS 宽只选择窄屏分支，避免重复使用浏览器宽度缩放同一组合。

## 数据及预留接口

`HomeController.configurePackBrowsing(readState, blocked, onPreviewAction?)`：

| 接口 | 用途 |
| --- | --- |
| readState(id) | 返回 HomePackState：解锁、真实库存／容量、任务进度及特殊款所有权 |
| blocked() | 子页面、弹层／会话等期间拦截浏览；DemoFlow 已覆盖现有页面面板 |
| onPreviewAction(id) | 非王溪烟盒主按钮及烟盒点击，供后续解锁、兑换或取烟业务接入 |

王溪数据取现有 PackStore，其他普通款与选盒页共用 createPackUnlockProgressReader。无影烟仅在 unlocked=true 时加入，祖国仅在 owned=true 时加入，不能用“有皮肤图片”或普通任务计数代替取得证据。当前没有这两项取得数据，因此默认 8 款；有真实数据源后可动态成为 9 或 10 款。

切换同步外观、页码、锁条件／进度、剩余读数及主按钮。未接其他烟盒库存时显示“—”，不复用王溪数字或画出假库存段。锁态主按钮为“查看解锁条件”，华孑为“用 2 张烟票解锁”；DemoFlow 已通过 onPreviewAction 接通旧包普通提示、兑换确认和打卡分支，兑换事务继续保留接口，不扣票或模拟成功。非王溪页面不调用原开盖／取烟操作；defaultSlot、getExtractionSource 也显式拒绝返回王溪烟支，避免借用真实库存。

当前浏览索引只在运行内保留，返回首页恢复浏览位置；不会写永久 selectedPackId。其他已解锁款实际开盖、取烟及持久选择仍需业务适配。特殊款首页的专用正面／立体切换控件未在本轮接入；其进入集合的证据接口与共用基础盒体已保留。

## 输入与资源

烟盒视口祖先使用捕获阶段接收触摸，先判定手势，再决定是否传给王溪的开盖／槽位 TOUCH_END。方向取消、多点触摸、无对应开始的松手均不转为点击；触摸取消不影响下一次正常手势。竖向手势锁定后不能改判成横向切换。阈值为当前 Cocos 实现的 10／40 参考 CSS px，不是对微信原生 swiper 内部阈值的复刻。

轮播期间拒绝再次切换和主按钮操作；开盖、取烟过渡、子页面覆盖时拒绝开始切换。异步皮肤请求按款去重，晚到结果按 ID 更新有效页，失败再次浏览可重试；持有的 SpriteFrame 引用及运行时纹理在销毁时释放。页面被隐藏或覆盖时结束未完成切换状态，不影响原库存。
