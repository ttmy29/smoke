## 本次新增的正常画面口径

用户本次指出新附的两张图代表正常会话画面，其中第二张是点燃后带焦黑燃烧边与灰帽的常态。会话主体需要保持：居中竖烟、上部暗黑下部暖棕、顶部品牌及熄灭、右侧六枚竖排圆形工具、底部左右圆形弹灰与吐烟圈占位，中间为长按提示。
