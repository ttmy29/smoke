# 第一版静态画面参考

本地参考图位于 `docs/reference/`。截图中的时间、次数、库存是示例值，不是第一版业务规则。动态截图只能确认关键状态，不能单凭静态图推定精确运动轨迹与时长。

## 01 首页烟盒（`reference/01-home.png`）

- 近黑背景、暖金细线与文字、橙色主操作按钮。顶部有小程序胶囊、奖励提示及“打卡／戒烟／收烟榜／成就”导航；其下是公告和库存区。
- 中下主体：左侧大幅“王溪 / WANG-XI”烟盒，盒盖打开，几根香烟可见；右侧纵向信息卡含记录、烟雾实验室、换一盒、今日状态、派烟。底部有左右切换提示、文案和橙色“来一根”按钮。
- 第一版视觉重点：烟盒皮肤、打开的盒盖与露出的香烟、黑金布局、橙色 CTA。顶部导航、右侧信息卡可静态复现或简化，但暂缓功能不能表现为可用。
- 示例库存“5/10”在首版不按真实十根库存结算；若保留展示，应标记为演示数据。

## 02 取烟过渡（`reference/02-extraction.png`）

- 深黑空背景，烟盒在屏幕中下部偏左；一根竖直香烟从盒内向上升起，占据画面纵向中心。没有复杂 UI，突出从烟盒进入互动页的过渡。
- 第一版需要一个短暂、可打断但不重复启动的取烟过渡动画；完成后进入互动页。升起、移动与缩放的精确时长待录屏确认。

## 03 点火前互动页（`reference/03-session-before-ignition.png`）

- 顶部显示“王溪”、风味副标题、已过时间/当前提示和“熄灭”按钮。背景上部接近黑色，下部为深棕渐变。
- 一根未点燃的香烟竖直居中偏下，滤嘴在下，烟纸在上。左侧有“点火方式”，右侧纵向工具按钮（麦克风吸烟、音效、环境、实验室、派烟）。底部提示“长按画面点火”和小型声波装饰。
- 第一版重点还原纵向香烟比例、背景渐变、顶部状态、点火入口与底部提示。暂缓功能可保留灰化视觉占位，但不得直接接入微信服务。
- 此图是**点火前**状态，不能用它推定点燃后火光、烟量或吸入动作。

## 04 本次结果（`reference/04-result.png`）

- 深灰黑面板风格，标题“本次记录”、完成文案“这一根，抽完了”、记录已保存提示。
- 中部包含烟盒十格示意和四项统计：本根口数、用时、弹烟灰次数、吐烟圈次数；下方有日期轴。
- 底部四按钮：再来一根、换一盒、分享这根、回首页。第一版只实现“再来一根”和“回首页”；另外两个暂缓，展示时必须明确不可用。统计值用本次会话实际数据，不照抄截图示例。
- 截图中的十格和“已用 7/10”与完整库存系统相关，第一版只做静态示意或简化，不宣称库存已实现。

## 与当前需求的差异及缺图

旧画面包含烟票、库存、解锁、分享、麦克风、完整记录等入口；第一版范围已缩为三个页面和一次会话。实现时优先保留整体视觉节奏，不为凑齐截图按钮而加入未完成业务。

## 05–12 点火、吸入、呼出与弹灰

- `05-lighting.png`：打火机贴近烟头，出现焦黑边缘与橙色火点。
- `06-inhaling.png`：橙色圆环扩散；提示“慢慢吸气”，示例进度 1.1 / 3.0 秒。
- `07-exhaling-start.png`、`08-exhaling-cloud.png`：白色圆环和较浓的烟雾扩散；提示“慢慢吐气”，示例倒计时 2.9 秒、1.9 秒。
- `09-smoke-ring.png`、`10-smoke-dispersing.png`：烟圈在烟身下部附近形成并逐渐扩散；底部恢复“长按画面吸气，松手吐气”。右下角另有“吐烟圈”按钮，不能仅凭截图断言两者的触发关系。
- `11-ash-before-flick.png`、`12-ash-falling.png`：顶端灰帽先积聚，再有灰白色碎屑从烟头附近散出。用户提供的第 7、8 张截图完全相同，仅归档一份。

截图未能证明烟身缩短的具体速率、每段动画的持续时间或烟圈的触发方式，实施时参考旧版代码并保留可调整参数。
