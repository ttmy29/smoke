# 第一版静态画面参考

> 自 2026-09-29 起，旧包 UI 与行为以 V1.0.8 代码的最终生效规则为准。图片只补充大致区域、元素类别与整体构图；不得查看图片来测量控件位置、大小、间距或响应式比例。图片与代码冲突时，以 V1.0.8 代码为准。

本地参考图位于 `docs/reference/`。截图中的时间、次数、库存是示例值，不是第一版业务规则。本文件只记录视觉内容和概略分区；具体几何、控件位置与动画时长须从旧包代码确认，不能从单帧图片推定。

## 01 首页烟盒（`reference/01-home.png`）

- 近黑背景、暖金细线与文字、深色金属外框加橙色内层的主操作按钮。顶部有小程序胶囊、奖励提示及“打卡／戒烟／收烟榜／成就”导航；其下是公告和库存区。
- 首页不是按单组固定屏幕坐标摆放：按“标题与右上设置 → 四等分快捷栏 → 公告 → 本盒剩余/库存 → 中部左右工作区 → 左侧烟盒切换 → 底部文案和橙色主按钮 → V1.0.8 自定义导航”的纵向区域顺序排布，屏高变化时调整区域高度和间距。中部烟盒区域约占工作区宽度 61.5%，右侧固定按“抽烟记录、烟雾实验室、换一盒、今日状态、派烟”排序。
- 顶部四项与右侧五项按旧包原有图标、文字和控件样式绘制，不能用统一灰色占位卡代替；本阶段只还原 UI，点击无效果，不显示“暂未开放”反馈。
- 新盒初始合盖，盒内 10 根烟不可见、不可点。旧包开盖不是翻盖或位移动画：固定位置的盒盖外表面在约 500 ms 内淡出，同时盒盖内衬、盒口、烟槽和白色内衬淡入；完成后烟槽才可点。合盖时点击“来一根”则先完成该动画、再自动抽一根。返回首页时同一盒保持开盖，新盒重新合盖。
- 中下主体：左侧大幅“王溪 / WANG-XI”烟盒，盒盖打开，几根香烟可见；右侧纵向信息卡含记录、烟雾实验室、换一盒、今日状态、派烟。底部有左右切换提示、文案，以及带左右双箭头的橙色“来一根”按钮。
- V1.0.8 页面最底部另有固定的两等分自定义导航：“来一根／全服”。它不是上方橙色 CTA 的第二种画法；导航高按 57 px 加底部安全区预留，深色底、暖金选中色，选中项顶部有 24 × 2 px 橙色短线。本阶段两个导航入口只展示，点击无效果。
- 2026-09-29 已编码上述底部导航：左侧使用旧包香烟线框图标并保持选中，右侧使用地球线框图标；首页内容按导航剩余高度重新布局，414×780 等视口会进一步压缩中部工作区。当前仅通过 TypeScript 与静态检查，实际间距、图标线条和手机安全区仍待用户查看。
- 2026-09-29 按 V1.0.8 最终级联规则再次对齐按钮位置：设置、快捷栏“成就”和右侧功能列共用右边缘；快捷栏按 56 px 基线；右侧普通卡按 44 px、间隔 4 px，今日状态纵向填充剩余空间，整体列高 95.4% 并下移 3.52%；烟盒切换入口保持在左列下方。此处为代码对齐记录，尚非浏览器视觉验收。
- 2026-09-29 根据旧包左列 61.5%、盒体占列宽 86% 及当前盒额外 `scale(1.06)` 复核，上一版烟盒横向约小 6%、纵向约小 22%。当前保持烟盒中心与右侧按钮不动，将 330 × 600 设计盒体调整为 X 1.17／Y 1.50，显示约 386 × 900；动态画面仍待用户确认。
- 2026-09-29 仅从旧包 V1.0.8 样式复核烟盒与右列纵向位置：可见盒体顶/底为工作区约 3.36%/98.76%，右列高 95.4% 且下移自身高度的 3.52%，顶/底也约为 3.36%/98.76%。当前烟盒已对上这两条边界，右列原先整体低约 20.5 设计单位，现已上移；不依据截图改变烟盒大小。
- 第一版视觉重点：烟盒皮肤、打开的盒盖与露出的香烟、黑金布局、橙色内层与暖金扫光文字主按钮。顶部导航、右侧信息卡可静态复现或简化，但暂缓功能不能表现为可用。
- 示例库存“5/10”不可照抄为固定值；当前首页按本机王溪烟盒 10 槽的可用数量分两行显示“本盒剩余”和真实 `N/10 支`，其中数字明显大于单位；十段短条按数量从左到右显示橙色渐变。整盒结算/补盒仍暂缓。
- 2026-09-28 首页调整已编码：首页已拆为五个响应式区域，右侧五项点击静默无效果，当前王溪盒保存十槽与盒盖状态。库存文案已拆层并恢复橙色十段；主按钮恢复金属外框、橙色渐变内层、左右双箭头和四个圆形黑色铆点，并把暖金底字与 2.8 秒左向右亮带合成在同一 Canvas 字形中，避免双影。烟盒左侧面已由纯色改为同皮肤裁切暗化。开盖采用固定几何交叉显隐并保留与内盖相连的左侧结构面。当前仅通过类型与静态检查，仍须用户在同视口浏览器中确认。
- 盒内香烟检查（2026-09-28）：旧包开盒时可见的是两排棕金滤嘴顶端，具有深浅立体纹理、扁椭圆端盖、细绿环和王溪叶形小标；下半段由盒口/内衬遮挡。当前已用运行时 Canvas 材质代替平色圆角矩形，并把烟槽组右移；此轮仅通过静态检查，盒口遮挡、材质成像及取烟起始帧连续性仍待用户在浏览器对照。
- 2026-09-28 滤嘴逻辑复核后，盒内烟改用旧包两层重复浅斑、按比例叶形和椭圆端盖；后排整根降亮度/饱和度。先前的取烟前段同材质覆盖层已移除，入场改用与游戏烟相同的 `CigaretteView` 材质；盒内到入场起点仍须视觉核对。绿环原位置正确，未挪动。基础空槽现已由本机库存驱动；旧包预留/取消回滚仍未移植。此处是代码静态修正，非截图视觉验收。
- 2026-09-28 整体差异复核与本轮修改：用户指出旧包烟盒整体更大、盒内烟更靠下、两排高度差和背景不同。旧包代码确认烟槽组为盒高 52%、两排顶端差盒高 8.32%；当前代码已改用该比例，盒口/内衬/盒身亦共用盒体百分比坐标。首页改为近黑渐变、弱暖光与暗角；同一王溪 256×384 原图改为放大裁切进盒身。整盒纵向增大且下移，但整体外框、层序和材质还需用户在同视口浏览器画面验收，不将静态检查写成视觉等效。

## 02 取烟过渡（`reference/02-extraction.png`）

- 深黑空背景，烟盒在屏幕中下部偏左；一根竖直香烟从盒内向上升起，占据画面纵向中心。没有复杂 UI，突出从烟盒进入互动页的过渡。
- 旧包代码已确认默认取烟运动 1350 ms、前奏 220 ms、前 28% 盒口遮挡；点击总时长还受未开盒盖时的 500 ms 开盖、Canvas 就绪与 480 ms 烟盒渐隐影响。图只能确定构图，运动轨迹与时间以旧包方法为准。
- 当前代码已按选中烟槽的位置入场，保留首页烟盒并裁剪前段烟身；图中滤嘴、盒口的具体比例与入场交接仍需用户在浏览器对照，不能将编译通过视作视觉等效。

## 本次新增的正常画面口径

用户本次指出新附的两张图代表正常会话画面，其中第二张是点燃后带焦黑燃烧边与灰帽的常态。会话主体需要保持：居中竖烟、上部暗黑下部暖棕、顶部品牌及熄灭、右侧六枚竖排圆形工具、底部左右圆形弹灰与吐烟圈占位，中间为长按提示。

吸气时在画面中央显示随 0–3 秒进度扩大的橙色圆环；满 3 秒进入吐气，烟雾由靠下的居中起点向上冒。这里的橙/白“呼吸圆环”属于吸吐气反馈，不等同于可选的“吐烟圈”工具。
