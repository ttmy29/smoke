## 生效条件与一致性

- 打卡、烟盒、个人初始数据在重置开关为 true 时应用；false 时读取并保留已有存档。
- 三个 Store 各自提供 `initializePreview` 接口，负责验证与写入；只向空存档写入，已有当前或旧版存档时拒绝覆盖。非法参数／写入失败在控制台提示；各存档独立初始化，不提供跨键事务。
- 累计天数、连续天数、烟票余额已经分开，不再随同一个参数联动。请同时满足 `连续天数 <= 累计天数`。例如累计改为 0 时，连续也须改为 0，烟票可保留任意有效余额。
- 今天已打卡为 false 且连续天数大于 0 时，末次打卡日设为昨天；连续为 0 时末次日期为空。今天已打卡为 true 时末次日期为今天，不自动再发票或补弹解锁提示；烟票余额采用配置值。
- 默认音效偏好、调试日志、广告预览每次启动读取，不依赖重置开关；音效开关与音量目前不写入用户偏好存档。
- 初始化的累计值会参与现有首页锁态与成就同步；单独修改累计抽烟数不会构造实际会话或烟盒结算证据。
- 记录页已接入，累计打卡至少 3 天可打开。初始累计／余额不生成历史明细；重置时也会清除 `smoke.records.v1` 中的抽烟明细和烟费估算单价，保留实际记录须将重置开关设为 false。范围见 [记录页](records-page.md)。
- 实验室累计至少 2 天开放；指向烟圈为 3 天、手指拨烟为 4 天。`smoke.lab.v1` 中的方案、互动偏好和每日权限一并受启动重置控制；范围和未接入项见 [烟雾实验室](smoke-lab.md)。
- 当前实验室 UI 预览独立于上述真实存档和广告开关，本次运行内的预览随重启清空，即使关闭存档重置也不持久化；后续实际烟雾效果接入预留回调。
- 广告开关作用于当前内置 PreviewRewardedVideoGateway；未来外部注入真实网关时由网关管理其可用性。

## 查看打卡解锁弹层

保持 `RESET_LOCAL_SAVE_ON_START = true`、`INITIAL_CHECKED_IN_TODAY = false`。

| 想查看的弹层 | 累计天数 | 连续天数示例 | 操作 |
| --- | --- | --- | --- |
| 第 1 天 | 0 | 0 | 重新运行后点打卡 |
| 第 2 天 | 1 | 1 | 重新运行后点打卡 |
| 第 3 天 | 2 | 2 | 重新运行后点打卡 |
| 第 4 天 | 3 | 3 | 重新运行后点打卡 |

烟票余额可单独填写，例如累计 2、连续 1、烟票 20；打卡后为累计 3、连续 2、烟票 21。查看后把重置开关改回 false。

## 后续接口接入

- 戒烟天数：在 QuitStore 增加逐日预览记录初始化，再由 DemoFlow 在重置分支调用；需要明确起止日期、今日确认状态及感受记录，不能仅覆盖统计显示值。
- 多烟盒：扩展烟盒 ID 类型、资源目录和库存存档解析，再扩展 PackStore 的 `initializePreview` 支持范围。
- 新增参数同时补齐类型、范围、生效时机、运行代码读取点和本表状态，完成后再将“预留”改为“已接入”。
