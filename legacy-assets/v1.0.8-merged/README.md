## 接入时需要注意

1. **版本与音源选择。** 来源是 V1.0.7／V1.0.8 合并目录，`-1` 与原名部分相同、部分不同。按 V1.0.8 最终代码、逻辑路径和实际音源确定取哪一份，不能一律替换为 `-1`。
2. **导入与引用。** 确定使用后再将选定文件复制到合适的 Cocos 资源目录，由 Creator 生成 `.meta`。已有资产的 `.meta` 和 UUID 应保留，避免预制体引用失效；不要将原微信 JS／HTML 子包当作 Cocos 资源导入。
3. **功能链路。** 音频仍需接入触发条件、音量、独立开关、循环／停止和资源释放；皮肤仍需选盒、解锁、独立库存及滤嘴／盒盖主题。复制完成不代表功能完成。
4. **构建与平台。** 按使用范围决定放入 `resources` 还是独立 Bundle，避免全部常驻；微信／原生播放、加载及纹理导入需要目标平台检查。视觉和听感由用户验收。
5. **来源与发布。** 沿用工程既有临时旧素材约定，接入处记录 `LEGACY_ASSET`、`TODO_REPLACE`，发布前确认素材使用权。
